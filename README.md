# Udemy-dashboard
This project provides a comprehensive data analysis of Udemy Online Courses using a dynamic dashboard. It explores market trends, subscriber demographics, and the pricing strategies across various subjects.

## 📊 Udemy Online Courses Analysis Dashboard
A comprehensive data visualization project analyzing the trends, pricing strategies, and subscriber engagement of online courses on the Udemy platform. This project transforms raw data into actionable insights using an interactive dashboard.

## 🚀 Project Overview
This project provides a deep dive into the Udemy marketplace between 2011 and 2017. It explores the relationship between course subjects, pricing tiers, and student enrollment to understand what drives success in the e-learning industry.

## 💡 Key Insights
Massive Reach: The platform achieved a total of 12M subscribers across 3.68K courses.

Dominant Subjects: Web Development is the leading category with 7.9M subscribers, followed by Business Finance with 1.9M.

Pricing Trends: The average course price is $66.1, with the highest price reaching $200.

Content Growth: Course production saw exponential growth, peaking in 2016 with 1,204 new courses.

Monetization Balance: The dashboard analyzes the distribution of Paid vs. Free content and how payment status affects the number of lectures and reviews.

## 🛠️ Features
Overview Page: High-level metrics including total subscribers, reviews, and course counts.

Price Analysis: Detailed breakdown of "Price Categories" (Free, Cheap, Average, Expensive) and their impact on enrollment.

Course Details: A granular look at individual course titles, levels (e.g., Beginner Level), and specific lecture counts.

Interactive Navigation: Sidebar navigation to switch between Home, Overview, Price Analysis, and Course Details.

## 📈 Visualizations Included
Line Charts: For tracking course growth by year.

Bar Charts: Comparing subscribers and average prices across subjects like Graphic Design and Musical Instruments.

Donut Charts: Visualizing the split between Paid and Free content.

Scatter Plots: Analyzing the correlation between course duration, price, and subscriber counts.

## 🧰 Tech Stack
Tool: Power BI (Business Intelligence)

Power Query: Data transformation and cleaning.

Data Source: Udemy Courses Dataset (kaggle)
